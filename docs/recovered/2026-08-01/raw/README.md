# Byte-exact source archive

This directory contains the 22 files supplied to the interrupted research
session, copied byte for byte before any whitespace normalization, filename
normalization, mathematical correction, or promotion into active Lean source.

- `uploads/` contains the seven directly uploaded files, including the Python
  companion and the original `Markdown.md colado` separator line.
- `project_sources/` contains the eleven long-form records and four Lean
  drafts using their stable transport filenames.
- `SHA256SUMS.txt` authenticates every raw payload. From this directory, run
  `sha256sum -c SHA256SUMS.txt`.

The readable files one directory above and the active Lean modules remain the
editorial/kernel authorities. They may correct terminology or proof comments;
this raw archive is the preservation authority for the received bytes.
